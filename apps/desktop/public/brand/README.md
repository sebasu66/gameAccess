# GameAccess brand assets used by the app

- `logo-header-poster.png`: the voxel logo still; the window icon (`index.html`).
- `logo-opening.mp3` and `opening-audio.json`: the opening's sound (SplashScreen).

The animated voxel logo videos (header loop, intro, entry) are no longer used by the app: the logo is the one on the
opening cover. The website keeps its own copies in `deploy/website/assets/brand`; `tools/brand` can render them again.
