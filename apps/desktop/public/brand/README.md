# GameAccess voxel brand

Approved G/A perspective logo rendered from the Three.js voxel scene, with reflective white exterior, orange interior and self-shadows. VP9 WebM assets have transparent backgrounds.

- `logo-header-loop.webm`: 192 × 192, 28.6 s seamless rotation, animated perspective.
- `logo-intro.webm`: 1920 × 1080, 3.6 s, cubes arriving from all directions.
- `logo-to-header.webm`: 1920 × 1080, 3 s, independent voxel motion and shrinking.
- `logo-header-poster.png`: transparent still and decoder fallback.

`referencePixelEffects.js` retains the supplied HTML's rendering functions verbatim. Its adapter scopes LED backgrounds to main screen controls, supports saved sliders and cleans up observers/animation on unmount. Settings and dialog controls use ordinary backgrounds.
