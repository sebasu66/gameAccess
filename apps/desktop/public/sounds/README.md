# gameAccess Library UI sounds

Drop these optional files in this folder:

- `library-move.mp3` — plays when the player moves the selection between games/actions.
- `library-activate.mp3` — plays when the player enters/activates an action with Enter or click.

No code/config change is required. Missing files are silently ignored. During Vite/Tauri development, adding or replacing either file is picked up by the next interaction.
